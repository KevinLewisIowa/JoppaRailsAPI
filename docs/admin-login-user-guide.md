# Joppa Admin Login Guide

**Subject:** Joppa admin account setup

Hello,

You have been given access to the Joppa admin application. Please use the instructions below to sign in and create your permanent password.

## First login

1. Open the Joppa application:
   **https://joppa-ui-prod.herokuapp.com**
2. Select **Admin Login** on the login page.
3. Enter your email address:
   **[INSERT USER EMAIL]**
4. Enter the temporary password provided to you:
   **[INSERT TEMPORARY PASSWORD]**
5. Select **Login**.
6. You will be taken to the **Change Password** screen. You must create a new password before continuing.
7. Enter the temporary password as your current password.
8. Enter and confirm your new password.
9. Select **Change Password**.
10. After the password changes successfully, select **Admin Home** to continue using the application.

## New password requirements

Your new password must:

- Be at least 8 characters long
- Include at least one uppercase letter
- Include at least one number
- Include at least one special character, such as `!`, `@`, `#`, or `$`

Spaces are allowed in passwords, so a passphrase may be used as long as it meets the requirements above.

## After setup

On future visits, select **Admin Login** and use your email address with your new password. You will not need to use the temporary password again.

Please do not share your password. If you believe someone else may know it, contact the Joppa administrator so it can be reset.
